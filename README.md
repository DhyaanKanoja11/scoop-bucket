# Scoop Bucket for Dhyaan Kanoja's Developer Tools

Personal Scoop bucket for developer tools by Dhyaan Kanoja, including [Lantern](https://github.com/DhyaanKanoja11/Lantern) — a local-first security CLI explaining configuration causality behind exposed services.

## Installation

Add this bucket to Scoop:

\\\powershell
scoop bucket add dhyaan https://github.com/DhyaanKanoja11/scoop-bucket
\\\

Install Lantern:

\\\powershell
scoop install lantern
\\\

Update Lantern:

\\\powershell
scoop update lantern
\\\
